# RESOURCES.md format

`RESOURCES.md` is the curated set of trusted sources for the topic. Lessons draw knowledge from here, not from memory. Wisdom comes from the communities listed here.

## Structure

```md
# {Topic} resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_, Zatsiorsky and Kraemer](https://example.com)
  Foundational text on programming and adaptation. Reach for it on periodisation, recovery, and intensity zones.
- [Article: "How Much Should I Train?", Greg Nuckols, Stronger By Science](https://example.com)
  Evidence-based review of volume landmarks. Reach for it on weekly set targets per muscle group.

## Wisdom (communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Reach for it on programme critique and plateaus.
- Local: Tuesday strength class at {gym name}
  Reach for it for live coaching feedback on lifts.
```

## Rules

- **High trust only.** Prefer primary sources, recognised experts, peer-reviewed work, and well-moderated communities. Leave out marketing dressed as education.
- **Annotate every entry.** One line on what it covers and when to reach for it. A bare link is useless in three months.
- **Knowledge or wisdom.** Knowledge is sources for lessons. Wisdom is communities for real-world testing. Each resource sits in one group.
- **Name the gaps.** When no good resource exists for an area the mission needs, list it under `## Gaps`. That drives the next search.
- **Prune.** Remove a resource that proved wrong, shallow, or off-mission. Five sharp sources beat thirty mediocre ones.
- **Record community preferences.** If the user opted out of communities, say so here so later sessions stop proposing them.
